# Assets

Плейсхолдеры. Перед релизом заменить на финальные ассеты бренда:

- `icon.png` — 1024×1024, иконка приложения (добавить и прописать в `app.json`
  `ios.icon` / `android.adaptiveIcon.foregroundImage`).
- `splash.png` — сплэш-экран (добавить в `app.json` `splash.image`).
- `notification-icon.png` — монохромная иконка уведомления Android (сейчас —
  прозрачный плейсхолдер 1×1).

Пока заданы только цвета фона (`#0B1120`) — приложение собирается и запускается,
но с дефолтной иконкой Expo.
